## 🔧 Quick Start

```bash
# Clone the repository
git clone https://github.com/ad9xholdings/jamzia-networks.git
cd jamzia-networks

# Install dependencies
npm install

# Configure environment
cp .env.example .env
# Edit .env with your settings

# Run tests
npm test

# Start development server
npm run dev
```
